UNIT 01 · FUNDAMENTALS

基本計數原理

所有組合計數的起點：判斷題目是在「分情況」還是「分步驟」。

加法原理 vs. 乘法原理

OR · 加

互斥的不同情況

若方案 A 有 \(m\) 種、B 有 \(n\) 種，且兩者不重疊：

\[m+n\]
AND · 乘

依序完成的步驟

第一步有 \(m\) 種選擇，且每個選擇都可接續 \(n\) 種：

\[m\times n\]
辨題口訣：「或」通常加，「且／依序」通常乘；有重疊時，不能直接相加。

補集計數與分類討論

補集法

算「至少一個」或「不是全部」時，通常先算全部，再扣除不符合者。

\[|A^c|=|U|-|A|\]

分情況加總

依某個關鍵條件切成互斥且涵蓋全部的情況。

\[|U|=\sum_{i=1}^{r}|A_i|\]
UNIT 02 · ARRANGEMENTS

排列、組合與分配

先問「順序要不要算」與「物件可不可以重複」。

排列與組合的核心比較

排列 Permutation

選出 \(r\) 個相異物件，順序有差。

\[P(n,r)=\frac{n!}{(n-r)!}\]

組合 Combination

選出 \(r\) 個相異物件，順序不計。

\[\binom{n}{r}=\frac{n!}{r!(n-r)!}\]

延伸重要公式

階乘

\[n!=n(n-1)\cdots1\]

定義 \(0!=1\)。

重複元素排列

\[\frac{n!}{a_1!a_2!\cdots a_k!}\]

相同物件互換不產生新排列。

重複選取序列

\[n^r\]

\(r\) 個位置、每格 \(n\) 種，允許重複。

特別注意：相異人／物、相同人／物、可重複／不可重複、是否允許空組，會改變公式。

二項式係數恆等式

\[\binom nr=\binom n{n-r}\]
\[\binom nr=\binom{n-1}r+\binom{n-1}{r-1}\]
\[\sum_{r=0}^{n}\binom nr=2^n\]
UNIT 03 · EXPANSION

二項式與多項式定理

將「展開式係數」轉換成「有幾種選擇位置的方式」。

二項式定理 Binomial Theorem

\[(x+y)^n=\sum_{k=0}^{n}\binom nk x^{n-k}y^k\]

\(\binom nk\) 代表在 \(n\) 個因子裡，選出 \(k\) 個提供 \(y\)，其餘提供 \(x\)。

Pascal 三角形：每個內部數字等於上方相鄰兩數相加。

多項式定理 Multinomial Theorem

\[(x_1+\cdots+x_k)^n=\sum_{n_1+\cdots+n_k=n}\frac{n!}{n_1!\cdots n_k!}\prod_{i=1}^{k}x_i^{n_i}\]

其中 \(n_i\ge0\)。指定各變數的次方後，係數就是多項式係數。

求係數的檢查順序

① 次方總和要等於 \(n\)。② 確認每個指數。③ 套入階乘分母。

係數總和

所有變數都代入 1，即可得到展開式全部係數加總。

\[k^n\]
UNIT 04 · DISTRIBUTION

隔板法與整數解

把相同物品分配問題，轉換成星星與隔板的排列問題。

隔板法 Stars and Bars

非負整數解

\[x_1+\cdots+x_k=n\]\[x_i\ge0\]
\[\boxed{\binom{n+k-1}{k-1}}\]

正整數解

\[x_1+\cdots+x_k=n\]\[x_i\ge1\]
\[\boxed{\binom{n-1}{k-1}}\]
下限為 \(a_i\) 時，先令 \(y_i=x_i-a_i\)，化成非負整數解。若另有上界，通常還須用分類或容斥扣除違規情況。

互動：整數解數量

UNIT 05 · BINARY STRINGS

二元字串、Run 與 Composition

從「位置選擇」到「連續區塊」，掌握字串題目背後的計數方法。

二元字串 Binary Strings

長度為 \(n\) 的所有字串

\[2^n\]

每一位獨立選 0 或 1。

恰有 \(r\) 個 1

\[\binom nr\]

相當於選出哪些位置放 1。

Run：相同符號的極大連續段

Run 是「無法再往左右延伸」的連續相同符號區塊。計數時，可將字串拆成區塊長度，再利用正整數解或分類討論。

\[a_1+\cdots+a_r=n,\qquad a_i\ge1\]
注意「恰有幾個 1」與「恰有幾段連續的 1」是不同條件；字串兩端是否允許 0 也會影響答案。

Composition：整數的有序分拆

將正整數 \(n\) 拆成 \(k\) 個有順序且為正的部分：

\[\binom{n-1}{k-1}\]

若不限正整數部分的個數，則正整數 \(n\ge1\) 的 Composition 總數：

\[2^{n-1}\]
UNIT 06 · FUNCTIONS

函數、單射與滿射

分清楚 domain、codomain、range，以及每種映射的計數條件。

函數的四個基本名詞

Function \(f:A\to B\)

定義域 A 的每個元素，恰好指向 B 中一個元素。

\[\#\{f:A\to B\}=n^m\]

當 \(|A|=m,\ |B|=n\)。

Range 與 Codomain

Codomain 是指定的目標集合 B；Range 是實際被映到的元素集合，且 \(\mathrm{Range}(f)\subseteq B\)。

Injection、Surjection、Bijection

Injective

單射 One-to-one

不同輸入不會指向相同輸出。

\[P(n,m)=\frac{n!}{(n-m)!}\]

需 \(m\le n\)，否則 0。

Surjective

滿射 Onto

每個 codomain 元素都至少被映到一次。

\[n!S(m,n)\]

Bijective

雙射

同時滿足單射與滿射。

\[n!\]

當 \(m=n\)，否則 0。

典型易混淆：「每個人至少拿到一個物品」= Onto；「每個人最多拿到一個物品」並不自動等於 Onto。
UNIT 07 · SET PARTITIONS

Stirling Number 與容斥原理

此單元連結集合分割、物品分配與滿射計數，是習題的重要交會點。

第二類 Stirling 數 \(S(m,k)\)

將 \(m\) 個相異元素分成 \(k\) 個非空且不標號的集合之方法數。

遞迴公式

\[S(m,k)=kS(m-1,k)+S(m-1,k-1)\]

最後一個元素要嘛加入既有一組，要嘛自己成組。

邊界條件

\[S(m,1)=S(m,m)=1\]

另有 \(S(0,0)=1\)、\(S(m,k)=0\) 若 \(k>m\)。

若分給 \(k\) 個有名字的人／標號的盒子，且每人至少一個，則將分好的 \(k\) 組再指派給 \(k\) 人：\(k!S(m,k)\)。

容斥原理 Inclusion–Exclusion

當不同條件之間有交集時，透過「加、減、再加……」避免重複計數。

\[|A\cup B|=|A|+|B|-|A\cap B|\]
\[\#\text{Onto}(m\to n)=\sum_{j=0}^{n}(-1)^j\binom nj(n-j)^m=n!S(m,n)\]
容斥通常是從「所有函數」扣掉「至少一個目標沒被用到」的情況；扣除後再修正重複扣除部分。

互動：滿射與 Stirling 數

UNIT 08 · PIGEONHOLE + FINAL REVIEW

鴿籠原理與考前總整理

找出最少必然發生的重複或聚集現象；最後整理考前速查清單。

鴿籠原理 Pigeonhole Principle

基本形式

\(n+1\) 個物件放入 \(n\) 個盒子，至少某盒有兩個物件。

\[n+1\to n\quad\Rightarrow\quad\ge2\]

廣義形式

\(N\) 個物件分入 \(k\) 個盒子，必有一盒至少：

\[\boxed{\left\lceil\frac Nk\right\rceil}\]
證明三步驟：① 誰是鴿子 ② 誰是籠子 ③ 如何對應。整數、餘數類、幾何區域等都可以作為籠子。

考前公式一頁速查

題型公式／概念使用關鍵
有序選取\(P(n,r)=n!/(n-r)!\)順序有差、不可重複
無序選取\(\binom nr\)只選集合、不計順序
相同元素排列\(n!/(a_1!\cdots a_k!)\)交換相同物不另計
正整數解\(\binom{n-1}{k-1}\)每組至少一個
非負整數解\(\binom{n+k-1}{k-1}\)允許空組
所有函數\(n^m\)\(m\) 個輸入，\(n\) 個目標
單射\(P(n,m)\)每個輸出至多被選一次
滿射\(n!S(m,n)\)每個目標至少被映到一次
非空集合分割\(S(m,k)\)不標號群組
鴿籠原理\(\lceil N/k\rceil\)至少有一籠的下界
